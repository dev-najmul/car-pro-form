# TUXANO client pricing guide

[Download the editable Word guide](TUXANO_Pricing_and_Rate_Management_Guide.docx).

The nine-page English guide explains Mileage-Based and Time-Based Transfer pricing, independent Hourly Booking rates, waiting, extras, gratuity and per-vehicle/global rate updates. It includes nine actual administration screenshots and worked USD examples for Tuxano Booking 2.6.1.

Values are supplied/reference examples rather than a live-site rate audit. The guide was checked against the current pricing implementation, rendered to PDF and visually reviewed for page layout and readability.
